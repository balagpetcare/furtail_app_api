# Source Inventory

## Dhaka North City Corporation (DNCC)
* Primary Source URL: https://dncc.gov.bd
* Available Formats: HTML, PDF, CSV (for limited datasets)
* Extracted Sections: Location & Area (`/pages/static-pages/...`), Councilors Directory.
* Notes: OCR was required for embedded PDFs containing zone mappings. Wards are dynamically distributed among zones.

* Primary Source URL: https://dscc.gov.bd
* Available Formats: HTML, PDF
* Extracted Sections: Location page (`/pages/static-pages/...`), embedded legacy PDFs.
